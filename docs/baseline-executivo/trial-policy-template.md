# TrialPolicy — `[PRODUCT_ID]`

> Conforme a Arquitetura Mestre, lida integralmente e consolidada pela Fase 0 v1.2, a plataforma deve possuir um Trial & Conversion Engine, com política por produto, durações distintas e políticas de cartão distintas. Isso não significa que qualquer produto tenha trial comercial liberado.

## Regra para o portfólio inicial

Kordena, Iron Fit, Vendedor IA, CampaIA, Super Core Extreme e ERP Core começam com `trial_policy: PENDENTE_EVIDENCIA`. Esta revisão não autoriza escolher duração, exigência de cartão, limites ou plano.

## Identificação

| Campo | Valor |
| --- | --- |
| Product ID | `PENDENTE_EVIDENCIA` |
| Política ID/versão | `PENDENTE_EVIDENCIA` |
| Trial disponível | `PENDENTE_EVIDENCIA` |
| Evidência específica | `PENDENTE_EVIDENCIA` |
| Estado | `bloqueado` |
