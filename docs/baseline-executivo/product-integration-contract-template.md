# Product Integration Contract — `[PRODUCT_ID]`

> Contrato documental, não executável. Sistemas, provedores e integrações só podem ser nomeados quando confirmados pela Fase 0.

## Modelo de desacoplamento para os seis produtos

```text
Website / FM Platform
        ↓
Product Integration Contract
        ↓
Product-specific tenant/workspace
        ↓
Entitlements
        ↓
Produto operacional
```

O site comercial não deve acessar diretamente bancos de dados dos produtos. Um contrato deve ser instanciado por produto, sem presumir endpoint, provedor, tenant API ou contrato operacional.
